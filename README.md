# math-modeling

数学建模竞赛资料仓库：赛题、模型代码、优秀论文、工具脚本

## 目录结构

| 目录 | 内容 |
|---|---|
| [赛题/](赛题/README.md) | 往届真题（国赛、美赛、电工杯等）+ 解读笔记 |
| [模型代码/](模型代码/README.md) | 预测/优化/评价/统计/微分方程模型的可复用代码 |
| [优秀论文/](优秀论文/README.md) | 获奖论文存档 + 赛后复盘 |
| [工具脚本/](工具脚本/README.md) | 数据清洗、画图模板、论文排版模板 |

## 使用约定

- 每道赛题一个子目录：`年份-赛题名/`
- 代码统一注释头部：题目、模型方法、依赖库、运行方式
- 论文命名：`比赛-年份-题目-奖项.pdf`
